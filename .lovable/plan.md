# План: уведомления о заявках на email

## 1. Email-уведомление при новой заявке

При отправке формы клиентом:
- заявка сохраняется в базу (уже работает);
- параллельно на **nurhat_85@mail.ru** уходит письмо со всеми данными заявки (имя, телефон, email, компания, продукция, количество, сообщение, страница-источник, дата);
- клиент видит сообщение «Заявка отправлена» (уже работает).

### Что для этого нужно настроить
- Подключить email-домен через Lovable Cloud (одноразовый шаг — откроется диалог настройки домена, нужно будет добавить NS-записи у регистратора домена; до подтверждения DNS письма копятся и уходят после верификации).
- Развернуть инфраструктуру отправки писем и серверную функцию, которая шлёт уведомление.
- Подключить отправку к форме заявки (`RequestForm.tsx`) — после успешной записи в базу триггерится письмо. Если письмо не ушло, заявка всё равно сохранена — ничего не теряется.

### Шаблон письма (на русском)
Тема: `Новая заявка с сайта — {Имя}`
Содержимое: таблица со всеми полями заявки + ссылка на страницу-источник + время.

## 2. Просмотр заявок

Админ-панель не делаем. Заявки смотрите через кнопку **View Backend** → Database → таблица `leads`. Там же есть выгрузка в CSV.

## 3. Деплой на Vercel

База в Lovable Cloud работает с любого хостинга. Чтобы сайт на Vercel видел базу, в проекте Vercel в **Settings → Environment Variables** нужно добавить 3 переменные (точно такие же, как в локальном `.env`):

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`
- `VITE_SUPABASE_PROJECT_ID`

Значения я пришлю в чат после плана (это публичные ключи, их безопасно вставлять в Vercel). После добавления — Redeploy в Vercel.

## Технические детали

- Используется встроенная email-инфраструктура Lovable (pgmq-очередь + cron-обработчик, retry при сбоях).
- Шаблон письма: React Email в `supabase/functions/_shared/transactional-email-templates/new-lead-notification.tsx`, регистрируется в `registry.ts`.
- Отправка: вызов `supabase.functions.invoke('send-transactional-email', ...)` из `RequestForm.tsx` после успешного `insert`. Ошибка отправки письма не блокирует пользователя.
- `idempotencyKey` = id вставленной заявки, чтобы при повторных кликах не дублировать письма.
- Получатель `nurhat_85@mail.ru` зашивается константой в edge function (не в клиентский код).
